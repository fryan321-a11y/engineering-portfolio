# Ryan Forbes — Mechanical Engineering Portfolio

Static portfolio site built for GitHub Pages.

## Publish on GitHub Pages

1. Open the `engineering-portfolio` repository.
2. Click **Add file → Upload files**.
3. Upload **everything inside this folder** (`index.html`, `style.css`, `script.js`, and the `assets` folder).
4. Commit the upload to `main`.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**, then Save.

Your site should appear at:
`https://fryan321-a11y.github.io/engineering-portfolio/`

## Before final launch

- Replace or remove any wording you do not want public.
- Add field photos of the 70-ft excavation if/when available.
- Add a final one-page resume as `resume.pdf`, then add a Resume button to `index.html`.
- If desired, purchase a custom domain later; it is not required for applications.

## Design intent

The site is deliberately static, fast, mobile-friendly, keyboard-accessible, and easy to maintain. It leads with the strongest mine-relevant field project, then provides proof of surveying, mechanical repair, and machining without forcing a recruiter through a complex navigation structure.
